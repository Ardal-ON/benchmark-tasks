# Benchmark submission repository

The upstream task repository is [robocurve/benchmark-tasks](https://github.com/robocurve/benchmark-tasks).

Work in a fork using the team's registered GitHub account. Before creating another checkout, inspect any existing `benchmark-tasks/` directory, its remotes, current branch and uncommitted changes. Read its `AGENTS.md`; create a separate branch from the latest upstream `main` and a single `tasks/<task-name>/` folder for each submission. Do not branch from `dev` or a previous task branch. See [agent_workflow.md](agent_workflow.md) for the full process.
