# Assemble a hanging carabiner chain

Development prototype. The first required physical milestone is gate opening and clipping through the fixed eye, then a released two-link assembly. The third assembly motion will be added only after that milestone works. The passive mechanism is validated; no assembly, full-score demonstration or Dream result has passed yet.

The three 20 g accessory carabiners have original compound-capsule frames, each 64.5 x 36.5 mm with a 4.5 mm section. Each separate 2 g gate uses a passive torsion spring (0.0005 Nm/degree, damping 0.00001 Nm seconds/degree, 0.02 Nm torque cap) and 0–30 degree physical stops, giving about 18.7 mm maximum surface opening. A centered 15 degree parent joint frame avoids the standalone backend's 180 degree boundary. The fixed D eye has a real open middle; its lower edge is 220 mm above the table and it sits 80 mm forward of the pole. Own gate/frame collisions are disabled at the hinge; contacts with all other objects remain physical. Joint stops prevent outward or excessive gate travel. Every link stays a freely moving rigid assembly after clipping.

`layout_seed=17` chooses the default realized layout, independently of the evaluation engine's internal scene seed. Optional layout seeds 23 and 41 exercise different positions, yaws and broad faces. `chain_task/geometry.py` contains the generator; the runtime logs generated and settled poses. The generator separates zones by more than85mm and varies yaw across360degrees and either broad face. Actual315-hull grasp checks pass for seeds17,23,41 with an appropriate180degree jaw flip. Arbitrary-seed accessibility rejection remains unfinished; do not treat untested seeds as validated. A diagnostic reseeding attempt retained the original spawn defaults and is explicitly excluded; separate fresh environments test optional layouts.

The native `top_cam=demo` and original wrist calibrations are unchanged, with 640 x 360 observations at 20 Hz. A fourth camera is diagnostic only. CPU physics runs at 240 Hz with CCD. A wrapper reads live PhysX body transforms after every physics step for the interlink transition audit; its 240Hz runtime readback was measured in the quiet test. A conservative0.9mm interbody rod penetration guard supplements the closed-loop transition check. The scorer uses signed intersections with each planar loop's spanning polygon, rejects tangencies conservatively and requires agreement in both directions. Center proximity is never an interlink test.

Install with `uv pip install --no-deps -e .`. Rebuild assets using `python build_assets.py` and run `python -m unittest discover -p 'test_*.py'`. The first quiet mechanism probe is:

```sh
inspect-robots run --embodiment yam_carabiner_chain -E task=task.py -E top_cam=demo -E device=cpu -E control_hz=20 -E cam_width=640 -E cam_height=360 -E object_jitter=0 -E layout_seed=17 --policy carabiner_hold_scripted --instruction "Make one hanging chain using all three carabiners. Clip one to the stand, then link each remaining carabiner through the previous one. Close all gates and let go." --seed 17 --max-steps 500 --scorer task_score --store-frames --no-rerun --log-dir run-quiet
```

This probe performs no assembly and should score zero. Fourteen offline scorer/topology cases and ten live integrity/reset checks pass. The elevated clamped-frame torque gauge measured4.001,10.013,20.103degrees under0.002,0.005,0.010Nm;0.020Nm reached30.00002degrees and removing torque returned to0degrees. These external-force fixtures are diagnostics only, never demonstrations. Units follow the [OpenUSD DriveAPI](https://openusd.org/dev/api/class_usd_physics_drive_a_p_i.html).

A corrected grasp is being evaluated. No second or third assembly motion is implemented. A full normal-action controller and released two-link physical milestone remain required.
